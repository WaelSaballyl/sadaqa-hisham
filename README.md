# صدقة جارية عن هشام سبع الليل

أذكار وأدعية وقرآن، نسأل الله أن ينفع بها وأن يجعلها صدقة جارية عنه.

https://waelsaballyl.github.io/sadaqa-hisham/

المصحف كاملًا متاح للقراءة داخل الموقع، مع تلاوة اختيارية لكل سورة بصوت مشاري راشد العفاسي. يعمل زر الإضافة إلى الشاشة الرئيسية بالتثبيت المباشر حين يدعمه المتصفح، أو يعرض خطوات الإضافة اليدوية.

نص المصحف من إصدار `quran-uthmani` عبر [Al Quran Cloud](https://alquran.cloud/)، محفوظ كما ورد من المصدر. التلاوات تُبث من [Islamic Network CDN](https://alquran.cloud/cdn) وتحتاج اتصالًا بالإنترنت.
